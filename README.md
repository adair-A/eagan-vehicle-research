## How to use these findings

Prices and listing details reflect the research date and may change. Advertised prices generally include identified dealer fees but exclude government charges unless stated. An active listing is not seller-confirmed physical availability. Recommendations are conditional on title/history review, a written out-the-door quote and an independent pre-purchase inspection. No dealer was contacted or money committed.

The reports preserve source links and clearly distinguish seller claims, verified listing facts, estimates and unknowns. Some history reports or dealer pages could not be read because of access challenges. Raw browser captures and the original chat transcripts remain local and are not included in this publication.

## Sharing

This repository is intended to be **private**. A repository URL alone does not grant access. Invite the recipient's GitHub account as a collaborator before sending the link. Do not enable public hosting to share these private reports.
